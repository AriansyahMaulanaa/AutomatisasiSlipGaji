# Sistem Otomatisasi Slip Gaji Karyawan

Project ini merupakan aplikasi berbasis Java Desktop yang digunakan untuk membuat dan mengirim slip gaji karyawan secara otomatis melalui email. Sistem ini dibuat untuk membantu proses penggajian agar lebih cepat, rapi, dan mengurangi kesalahan perhitungan manual.

Aplikasi ini dibuat sebagai bagian dari tugas mata kuliah Rekayasa Perangkat Lunak (RPL) dan juga digunakan dalam kegiatan Kerja Praktek.

## Fitur Utama

Aplikasi ini memiliki beberapa fitur utama, yaitu:

* Login sebagai Supervisor atau General Manager
* Import data presensi karyawan dari file Excel
* Perhitungan gaji otomatis berdasarkan data presensi
* Generate slip gaji dalam bentuk PDF
* Pengiriman slip gaji otomatis ke email masing-masing karyawan
* Preview slip gaji sebelum dikirim
* Penyimpanan data penggajian ke database

## Alur Kerja Sistem

1. User login ke dalam sistem
2. User mengimport file Excel presensi karyawan
3. Sistem menghitung gaji secara otomatis
4. Sistem membuat slip gaji dalam format PDF
5. Slip gaji dikirim ke email masing-masing karyawan
6. Data penggajian disimpan sebagai arsip

## Teknologi yang Digunakan

* Java (Desktop Application)
* Java Swing / JavaFX
* MySQL / SQLite
* Apache POI (membaca Excel)
* iText / OpenPDF (membuat PDF)
* JavaMail API (kirim Email)

## Tujuan Project

Tujuan dari pembuatan aplikasi ini adalah:

* Mengotomatisasi proses pembuatan slip gaji
* Mengurangi kesalahan perhitungan gaji
* Mempermudah pengiriman slip gaji ke karyawan
* Sebagai media pembelajaran dalam mata kuliah Rekayasa Perangkat Lunak
* Sebagai implementasi project saat Kerja Praktek

## Catatan

Project ini masih dalam tahap pengembangan dan akan terus diperbaiki serta ditambahkan fitur baru.
